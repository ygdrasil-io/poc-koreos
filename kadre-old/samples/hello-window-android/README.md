# hello-window-android

Android app for the shared `hello-window` handler.

## Purpose

Demonstrates Kadre API convergence on Android: the same `HelloApp` (copied from `samples/hello-window/commonMain`) runs on Android, iOS, and JVM without modification.

## Platforms

- Android (minSdk 24)

## Usage

```bash
./gradlew :samples:hello-window-android:installDebug
```
