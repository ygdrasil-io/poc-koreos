# hello-touch-android

Android app consuming the shared `hello-touch` multi-touch handler.

## Purpose

Demonstrates that `samples/hello-touch`'s `commonMain` touch handling code works identically on Android. Uses `HelloTouchHandler` from the shared library.

## Platforms

- Android (minSdk 24)

## Usage

```bash
./gradlew :samples:hello-touch-android:installDebug
```
