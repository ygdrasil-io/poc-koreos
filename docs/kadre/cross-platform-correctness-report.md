# Cross-platform correctness evidence plan

This traceability report records the required evidence contract. “Planned command” is not an execution claim; CI artifacts are expected paths until an actual workflow run produces them.

Capture contracts are target-specific: `compose-raster` and `android-triangle` both require exactly 800×600 pixels and at least eight visible colors. Their non-uniform visible regions must contain at least 4,800 and 24,000 non-background pixels respectively; `hello-triangle-baseline` is the 800×600 local reference contract (four colors, 4,800 non-background pixels). The validator derives background from the most frequent normalized RGBA pixel rather than assuming black.
