# Web

[common]\
data object [Web](index.md) : [RawDisplayHandle](../index.md)

Web display handle (browser / Wasm).

In the Web context, the display is implicitly managed by the browser; no additional pointer is needed at this level of abstraction. This singleton simply marks the display target as being the Web context.
