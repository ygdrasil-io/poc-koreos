# Key

[common]\
enum [Key](index.md) : [Enum](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-enum/index.html)&lt;[Key](index.md)&gt; 

Logical keyboard keys.

Covers the letters A–Z, the digits Digit0–Digit9, the function keys F1–F12, the navigation and modifier keys, as well as a fallback value [Unknown](-unknown/index.md) for unrecognized keys.
